OON JAI COMPANY LIMITED | ANNUAL ARCHIVE
1. Keep the Annual Archive Template, the original annual JSON backup, this importer, issued report PDFs and receipt files together in the protected company Drive. Make a separate Google Sheet copy for each year. Keep the original source account and copies until the company account can open the files.
2. In Accounting use Settings > System & Tools > Backup & Recovery > Portable data backup. Select the full year and Everything, Prepare backup copy, then Download JSON copy. Preserve the posted reports you use for comparison with matching dates, basis, currency and technical-account settings.
3. Browser-only route: open Importer.html locally, choose the JSON, and download the CSV. In the archive Sheet use File > Import > Upload > Insert new sheet(s), with text conversion OFF. Put the new tab name in Review Home B8. Never concatenate snapshots. The manifest check compares per-type counts. The JSON fingerprint identifies the file; retain it separately. Large backups may require a separate workbook and each year's full-period source. Do not represent a partial period as a full year.
4. For a direct Google Sheets menu on desktop, make the archive copy first. In Extensions > Apps Script add Code.gs and an HTML file named Importer; paste the corresponding files. Save and reopen the Sheet. Choose Annual archive > Import raw backup and authorize the current-workbook operation. The upload verifies staged rows before switching the active snapshot. Old inputs remain in the workbook. No Supabase, Marketplace or external API login is needed by the importer. This menu must be installed once per template before copying it; File > Make a copy preserves its bound script.
5. Copy the physical receipts and pictures into the company Drive. In Receipt Links enter the original document ID or source filename, the new company Drive URL and verification notes. Recheck the original SHA-256 when available. Opening the original Marketplace URL does not verify the private copy. For files outside the scanner, add your own journal ID and file references. Retain file-to-journal links for multi-entry PDFs.
6. Review Home, Trial Review, Ledger Review, Statements, Payroll Review and Compare stay within the workbook. Original Raw rows/parts in the selected data tab preserve the business records supplied in JSON. Keep the JSON itself for exact archival evidence and for embedded attachments. Retain reviewed PDFs for historical print appearance.
