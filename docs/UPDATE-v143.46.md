# Reconciliation and closing refinements v143.46

Submission reconciliation includes only assigned main asset fund accounts. Report types use a multi-select dropdown on desktop, tablets and phone. Actual fund balances appear in both received review screens and the printable submitted account report. Explanation is revealed and required only after entering a discrepant balance. Reconciliation reference controls and statement-reference requirements are removed.

Month-end eligibility is checked before confirmation, processing feedback or database requests. October remains open until November 1 in Asia/Vientiane. Processing feedback and period status occupy separate positions away from the main notification. The sidebar profile is the final child and stays at the bottom.

SQL: setup/INSTALL-RECONCILIATION-REFINEMENTS-v143.46.sql. No journal entries or historical reports are deleted or recalculated.
