## Repairs

ZIP document imports now run in a disposable worker with a 10-second deadline.
Archives are limited to 32 MB compressed, 4096 entries, 16 MB per decompressed
file and 64 MB total. Declared sizes are checked before inflation; actual streamed
bytes are also counted, so forged ZIP metadata cannot bypass the limits. Every
success, failure and timeout terminates the worker and releases its object URL.
The existing cached JSZip URL supports offline import. DOCX, ODT, PPTX, XLSX,
EPUB and preview extraction keep the existing caller interface.

PDF rendering failures after clone creation could leave a hidden iframe behind.
The download caller now removes its own cloned frame in a finally block and
releases any completed canvas even if packing the PDF fails.
