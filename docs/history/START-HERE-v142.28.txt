POSTING AND REVOCATION NOTES
Receipts are kept in operation_receipts14228. Do not clear them as routine cache;
they prevent an old pending request from posting twice. Archive them only with a
deliberate retention plan that also invalidates old client request references.
An employee's own historical report now requires current Workspace View plus
Documents View + Export. Removing those grants immediately denies new server requests.
Revocation cannot remove copies the employee already downloaded or printed.

does not silently repair or reclassify them. Staging's diagnostic reports counts.
