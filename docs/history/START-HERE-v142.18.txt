TO-DO LISTS — SEPARATE FROM UPCOMING TRANSACTIONS
The existing dedicated To-do Lists card contains these enhancements. Completing
or deleting a task never posts, pays, or deletes an upcoming transaction.
- Types: Regular task, Sequential checklist, Recurring task / checklist.
- Default editable templates: Journal / period closing, Payroll processing,
  Bank / cash reconciliation, PIT / SSO preparation.
- Add, edit, reorder steps by moving lines, and save reusable personal templates.
  Using a template creates a fresh checklist; the original template is retained.
- Ordered steps unlock in sequence; undoing a step resets later steps.
- Progress bar, completed count, percentage and next step; notification links
  open the relevant checklist.
- Optional due date/time and reminder date/time. Repeat reminders hourly,
  every two hours or every custom number of minutes, within a daily time window.
- Recurring tasks repeat daily, weekly, monthly or every N hours. Completing
  the checklist starts the next scheduled cycle and records the completed-cycle
  count plus the latest completed steps/time. Missed cycles are consolidated.
- Times use the device timezone. Reminders run while the app is open; this ZIP
  does not install an operating-system/background push notification service.
- Tasks and custom templates are saved per signed-in user, protected by the
  existing owner-only database policy. Failed saves retain the form; concurrent
  edits are checked to avoid silently overwriting another saved update.
