SQL maintenance templates

Choose one operation and download its SQL file. Edit the marked values, then run the complete file in your Supabase SQL Editor as the database owner.

For removal: Preview → Export → save the JSON backup → Delete. Use the same dates in each file. The deletion template asks you to confirm that the backup was saved.
